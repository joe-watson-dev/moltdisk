    FAQs: before you sweep.

    Straight answers about cleaning a developer Mac.

    Why is my Mac storage full when I barely have any files?

    On a developer Mac, the space usually goes to things you never see: node_modules and build folders in old projects, Xcode DerivedData, iOS simulator runtimes, package manager caches and editor extensions. Together they often take more room than all your apps. DiskSweep finds them and shows the size of each one.

    What is System Data on a Mac, and why is it so big?

    System Data is what macOS calls storage that doesn't fit its other categories: caches, logs, developer tools data, simulator files and more. DiskSweep cleans the developer and app parts of it, such as Xcode data, simulators, package caches and app caches. It doesn't touch Time Machine snapshots or macOS itself.

    Is it safe to delete node_modules?

    Yes. node_modules only holds downloaded packages, and npm, pnpm or yarn install brings them back. DiskSweep labels every node_modules folder Will need reinstall, shows when its project was last active, and moves it to the Trash so you can put it back.

    How do I clear Xcode DerivedData and old iOS simulators?

    DerivedData is safe to delete; Xcode rebuilds it on the next build. Old simulators and runtimes should be removed with xcrun simctl rather than deleted by hand. DiskSweep does both: it lists DerivedData, Archives and DeviceSupport with sizes, and removes simulators and runtimes through simctl, the way Xcode does.

    Can I find VS Code extensions I never use?

    Yes. DiskSweep reads activation logs and storage activity for VS Code, Cursor, Windsurf, Antigravity, Kiro and other VS Code-based editors, and shows each extension with its real name and last use. Extensions used in the last 30 days, recently installed ones and your active theme stay locked.

    Will DiskSweep delete something an open app is using?

    No. Caches, logs and data that belong to a running app show as In use and can't be ticked. DiskSweep checks again right before it deletes, and a built-in guard refuses folders like Documents, Keychains, Preferences and app data.

    Is DiskSweep an alternative to CleanMyMac?

    DiskSweep focuses on what developer tools leave behind: project folders in any language, Xcode data, simulators, package caches and editor extensions, with a safety label on every item. It's a free download with no subscription.

    Which Macs does DiskSweep run on?

    Macs with Apple silicon running macOS 15 Sequoia or later. Download the zip and move DiskSweep.app to Applications. The app isn't notarized yet, so the first time macOS blocks it: open System Settings › Privacy & Security and click Open Anyway.
